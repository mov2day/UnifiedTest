# Install note

Some ZIP viewers hide folders whose names start with a dot.

Codex needs the real files here:

.codex/config.toml
.codex/agents/builder.toml
.codex/agents/reviewer.toml

This archive also includes a visible mirror:

codex-config/config.toml
codex-config/agents/builder.toml
codex-config/agents/reviewer.toml

The `codex-config/` folder is only for visibility/inspection.
Do NOT rename `.codex` to `codex-config`.

If your extractor hides `.codex`, extract all files from the archive using Finder/Explorer,
or copy the visible TOML files into the matching `.codex/` paths manually.
